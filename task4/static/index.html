Method & limitations.

A simple explanation of how the prototype works and what its outputs mean.

01

Problem

Classify a structured road scenario into Low, Medium or High risk using weather, traffic, road condition, visibility, speed, time and road type.

CLASSIFICATION · TABULAR DATA
02

Model

A Scikit-learn pipeline applies one-hot encoding to categorical inputs and uses a Random Forest classifier.

RANDOM FOREST · ONE-HOT ENCODING
03

Evaluation

A held-out 20% test split calculates accuracy, weighted precision, weighted recall and weighted F1 score.

80/20 SPLIT · FIXED SEED
04

Interface

This responsive interface sends JSON to FastAPI and renders prediction, class probabilities and an input summary.

FASTAPI · JSON API

Limitations & ethics notes

  • Synthetic labels: high scores may reflect generated rules rather than real-world patterns.
  • Not validated for safety: this is not a certified navigation, emergency or road-safety tool.
  • Confidence is not certainty: model probability is not the true chance of an accident.
  • Bias and coverage: the dataset may not represent all locations, road users or weather conditions.
  • Human judgment: follow traffic laws and official guidance; do not rely on this demo to decide whether a journey is safe.
